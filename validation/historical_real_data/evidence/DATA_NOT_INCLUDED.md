# Third-party raw data is not redistributed

This public evidence package intentionally does **not** include raw/source samples copied from third-party datasets.

The historical gate test was run using the following sources. Reproduce the test by obtaining the data from the original publisher under its current license:

- BPI Challenge 2019 — https://figshare.com/articles/dataset/BPI_Challenge_2019/12715853 — CC BY 4.0
- BPI Challenge 2020 — https://figshare.com/articles/dataset/BPI_Challenge_2020_Domestic_Declarations/12692543 — CC BY-NC 4.0
- Olist Brazilian E-Commerce — https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce — CC BY-NC-SA 4.0

Included in this package are the framework-side gate records, derived test metrics, assurance outputs, source register and validator needed to inspect the decision logic. Raw datasets remain with their original publishers.
